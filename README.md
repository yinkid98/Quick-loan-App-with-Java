# 💼 Loan Processing System (Java Swing)

This is a desktop-based **Loan Processing System** built using **Java Swing**. It allows users to apply for loans and enables administrators to review, approve, and manage loan requests.

---

## 🖥️ Technologies Used

- Java (JDK 8+)
- Java Swing (GUI)
- JDBC (for database connection)
- MySQL / SQLite (optional, based on your setup)

---

## ⚙️ Features

### 👤 User Module
- Register new loan applicants
- Submit loan applications
- View application status
- Edit user details

### 🛠️ Admin Module
- Login authentication for admin
- View and manage loan requests
- Approve or reject loan applications
- Generate simple reports
